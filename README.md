# AccentBean
AccentBean is an 8 key macropad with a rotary encoder and an OLED Display. It has a detachable magnetic OLED case, and uses KMK firmware. The purpose of this macropad is to make typing diacritics easier by holding both letter and accent at the same time.

## Bill of Materials (BOM)
- 1x Seeed XIAO RP2040
- 4x 5x2mm magnets
- 4X M3x12mm SHCS Bolts
- 8x Cherry MX Switches
- 8x DSA Keycaps
- 8x 1N4148 DO-35 Diodes
- 1x EC11 Rotary Encoder
- 1x 0.91" 128x32mm OLED Display
- 1x Case (3 printed parts)
